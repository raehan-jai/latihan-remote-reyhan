📝 My To-Do List
TES TES TES TES

Aplikasi To-Do List sederhana yang dibuat menggunakan HTML, CSS, dan JavaScript.

Project ini cocok untuk latihan dasar web development, terutama DOM manipulation, event handling, dan "localStorage".

✨ Fitur

- ➕ Menambahkan tugas
- ✅ Menandai tugas sebagai selesai
- 🗑️ Menghapus tugas
- 🧹 Menghapus semua tugas
- 💾 Data tersimpan otomatis menggunakan "localStorage"
- ⌨️ Bisa menambahkan tugas dengan tombol "Enter"
- 📱 Responsive untuk perangkat mobile

🛠️ Teknologi

- HTML5
- CSS3
- JavaScript
- LocalStorage

📂 Struktur Project

todo-list/
├── index.html
├── style.css
├── script.js
└── README.md

🚀 Cara Menjalankan

1. Download atau clone project ini.
2. Buka folder project di VS Code.
3. Buka file "index.html".
4. Jalankan menggunakan browser atau Live Server.

🎯 Tujuan Project

Project ini dibuat sebagai latihan untuk memahami:

- Struktur HTML
- Styling menggunakan CSS
- JavaScript dasar
- DOM Manipulation
- Event Listener
- Array dan Object
- LocalStorage
- Responsive Design

📸 Preview

Aplikasi memiliki tampilan dark mode sederhana dengan fitur untuk menambah, menyelesaikan, dan menghapus tugas.
